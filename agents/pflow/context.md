# TriMetric

## Purpose
Piattaforma web (desktop e mobile) che unisce gli allenamenti di corsa, bici e nuoto, con analisi e programmazione, a complemento di Strava

## Stack
C#/.NET a microservizi (ASP.NET Core, YARP), React + TypeScript + Vite (PWA), PostgreSQL con TimescaleDB, NATS JetStream, Docker/Podman
